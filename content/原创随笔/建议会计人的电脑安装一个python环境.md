真的，不论你学不学 python，安装它，会给你带来莫大的收益。

我们先不论用 python 进行数据分析，单从工作自动化这个角度，都能节省大量的时间。这从何说起呢？

1. 你将重复的工作内容说给 AI，指定它做一个 python 的脚本，将 AI 给出的代码复制到 python 代码编辑器，执行它！你会有一种请了一位“数字员工”的快感！

2. 在网上搜索，有大量文章写 python 如何减轻工作量的文章，如果里面有代码，复制、执行！

会计人的电脑，怎么安装 python 环境呢？两种方法：

1. 安装Anconda，可以称它为最适合会计人的 python 环境，它自带了 python 程序和常用的库，代码编辑器 jupyter notebook 是网页版的，对新手非常友好，输出的数据排列整齐，利于会计的工作。但它有一个缺点，没有代码自动补全，如果要使用这个功能，还得单独安装插件，对新手有一定的难度。

2. 安装 Vscode，它也有类似 jupyter notebook 的代码编辑模式。由于 Vscode 是通用的代码编辑器，你输入的代码是用什么编程语言，需要配置一个解释器。它配置 python 解释器有两种方式，一种是，在安装了 Ancanda 的情况下，配置选用 Ancanda。第二种情况是，如果没有安装 Ancanda，需要单独安装 python 程序，然后在 Vscode里配置选用 python。使用 Vscode，对新手的最大好处是有代码自动补全功能。

以上两种方法，借助 AI ，十分钟就可以完成。

相信我，只要你收集了第一个脚本并在工作中得到了收益，你就会爱上它，会像仓鼠一样，疯狂的去收集自己适用的 python 脚本。恭喜你，你在会计赛道上，领先了！
